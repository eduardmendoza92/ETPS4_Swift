# ETPS4_Swift

## Aplicación de accesibilidad iOS

Proyecto Xcode desarrollado con SwiftUI para demostrar interfaces accesibles en iOS:

- VoiceOver y etiquetas de accesibilidad
- Dynamic Type
- Contraste normal, alto y oscuro
- Controles amplios para accesibilidad motora
- Alertas visuales, vibración y subtítulos
- Preferencias locales con `UserDefaults`

### Abrir en Xcode

1. Abrir `AccesibilidadIOS.xcodeproj`.
2. Seleccionar un simulador de iPhone.
3. Ejecutar con **Run** (`⌘R`).

Compatibilidad configurada: iOS 15 o superior.
Proyecto iOS de demostración de interfaces accesibles en SwiftUI.
